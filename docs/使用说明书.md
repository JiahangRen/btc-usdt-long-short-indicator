# BTC Indicator 使用说明书

## 启动

1. 安装 Node.js 18+。
2. 在项目目录运行 `npm start`。
3. 打开浏览器并访问 `http://127.0.0.1:8787`。

若使用 macOS 应用包装启动，请确认其内部脚本、`com.jeffereyreng.btc-indicator.plist` 中的 Node 与项目路径已适配本机。

## 基本操作

1. 在右上角选择优先数据源（OKX、Binance 或 Gate），按“刷新”更新数据。
2. 使用周期按钮或 `1D / 1W / 1M / 6M / 1Y` 切换图表范围。
3. 查看价格区的 24 小时开盘价、高低价、数据源和更新时间。
4. 阅读“当前规则信号”和“指标明细”；信号分数来自规则计算，并非机器学习预测。
5. 按需点击“计算共振”，获取 15 分、1 小时、4 小时、1 日的规则信号对照。
6. 在图表中悬停、缩放、横向移动或框选，以查看某段价格表现和高低点。

## 研究模块

- 回测：查看当前图表样本中规则策略的演示结果；不含完整交易成本。
- 预测/概率：基于历史样本训练的方向条件概率和验证统计，不表示未来必然涨跌。
- 跨市场联动：比较 BTC 与 SPY、QQQ 的近期相关性及研究模型输出。
- 杠杆与仓位：输入方向、持仓、保证金、杠杆和开仓价，查看理论强平参考、估算费用和历史波动触及频率。
- 形态与关键位：基于当前 K 线、均线、成交量和近期区间生成观察性描述。

## 故障处理

- 显示“行情暂不可用”：检查本机网络、代理或上游交易所是否可访问；页面会保留上次成功数据。
- 特定来源失败：换用其他数据源，或稍后重试；锁定来源时应用不会自动切换。
- 页面无法打开：确认服务进程仍在运行，并检查 `http://127.0.0.1:8787` 未被本机安全软件拦截。
- 端口冲突：使用 `PORT=其他端口 npm start` 启动，然后访问对应端口。

## 重要提示

本工具仅供市场研究与风险教育。加密资产波动很大，任何显示的价格、强平价、概率、目标或回测结果均不构成投资、交易或收益建议。
