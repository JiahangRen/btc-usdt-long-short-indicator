# BTC Indicator 开发文档

## 技术结构

```text
浏览器（public/index.html + app.js + styles.css）
            │ HTTP / JSON
本地 Node 服务（server.mjs，127.0.0.1:8787）
            │ HTTPS
OKX / Binance / Gate 行情接口；Yahoo Finance 历史接口
```

项目无第三方 npm 运行时依赖，使用 Node 原生 `http`、`fetch` 与静态文件读取能力。

## 目录说明

- `server.mjs`：本地 HTTP 服务、上游行情适配、缓存与 API 路由。
- `public/index.html`：页面初始结构。
- `public/app.js`：指标计算、图表绘制、研究模块和交互逻辑。
- `public/styles.css`：界面样式与响应式布局。
- `BTC Indicator.app/`：macOS 应用启动包装与图标资源备份。
- `com.jeffereyreng.btc-indicator.plist`：本机 launchd 启动配置样例（包含本机绝对路径，迁移时必须修改）。
- `docs/`：需求、开发、使用与功能说明。

## 本地开发

前置条件：Node.js 18 或更高版本。

```bash
npm start
```

访问 `http://127.0.0.1:8787`。语法检查：

```bash
npm run check
```

## 服务端 API

| 路径 | 用途 |
| --- | --- |
| `/api/market?interval=15m&limit=96&source=okx` | 当前价格和 K 线；`source` 可为 okx/binance/gate。 |
| `/api/status` | 服务状态、可用来源和缓存条目数。 |
| `/api/forecast-history` | 概率研究所需的 BTC 15 分钟与日线历史数据。 |
| `/api/correlation-history` | BTC、SPY、QQQ 的日线历史及指数最近收盘。 |

`/api/market` 会校验 K 线数值、排序后限制数量；自动模式并行探测来源，用户锁定来源时只请求该来源。行情缓存默认约 900ms，研究历史缓存约 5 分钟。

## 维护注意事项

- 新增数据源时，分别实现 ticker 与 K 线标准化，确保输出包含 `time/open/high/low/close/volume`。
- 前端的数值结论必须保留“研究用途、非投资建议”的表述。
- 不要提交 `node_modules`、`.DS_Store` 或运行日志；它们已在 `.gitignore` 中排除。
- `plist` 的 Node 路径和工作目录是机器相关配置，部署到其他 Mac 前应替换为目标机器的实际路径。
