# 服务器部署

前提：域名 `renjiahang1201.xyz` 的 A 记录指向服务器公网 IP，并开放 TCP 80、443、22。

在服务器执行：

```bash
git clone https://github.com/JiahangRen/btc-usdt-long-short-indicator.git
cd btc-usdt-long-short-indicator
docker compose up -d --build
```

Caddy 会自动申请并续期 HTTPS 证书，站点地址为 `https://renjiahang1201.xyz`。

启用性能面板：

```bash
docker compose --profile monitoring up -d
```

不要将 Netdata 端口暴露到公网。在本地 Mac 创建隧道后访问：

```bash
ssh -L 19999:127.0.0.1:19999 root@服务器IP
```

然后打开 `http://127.0.0.1:19999`。

## GitHub 推送后自动部署

仓库包含 `.github/workflows/deploy.yml`。向 `master` 推送后，GitHub Actions 会通过 SSH 将代码同步到 `/opt/btc-usdt-long-short-indicator`，重建容器并检查线上健康接口。服务器需要安装 `rsync`：

```bash
apt-get install -y rsync
```

建议使用专用部署账号；首次配置也可使用现有服务器账号。在部署客户端生成一对独立的 Ed25519 密钥，将公钥追加到服务器账号的 `~/.ssh/authorized_keys`，私钥只保存到 GitHub Actions Secret。

在仓库 `Settings → Secrets and variables → Actions` 中创建：

- `DEPLOY_HOST`：服务器 IP。
- `DEPLOY_USER`：SSH 登录用户名。
- `DEPLOY_SSH_KEY`：独立部署密钥的完整私钥。

工作流不会把 GitHub Token 保存到服务器。服务器上的 `.git` 目录会被保留，但线上文件以本次 GitHub 提交为准。
