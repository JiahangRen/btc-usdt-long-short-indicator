# BTC Indicator 需求文档

## 目标

提供一个本地运行的 BTC/USDT 市场观察与研究工具：以可追溯行情为基础，展示技术指标、规则信号、研究型统计与仓位风险参考。产品不提供自动交易，也不构成投资建议。

## 用户与场景

- 交易者在浏览器中查看 BTC/USDT 永续合约的最新价格、24 小时变化和不同时间范围的图表。
- 用户需要快速比较 EMA、MACD、RSI、布林带和 ATR 所表达的短期市场状态。
- 用户可按需查看多周期共振、历史研究型回测、概率研究、跨市场相关性、持仓盈亏和强平距离。

## 功能需求

1. 支持 OKX、Binance、Gate 三个数据源；用户选定来源后不得在失败时静默切换。
2. 支持 1 分、5 分、15 分、30 分、1 小时、2 小时、4 小时、1 日 K 线，以及 1 日、1 周、1 月、6 月、1 年快捷范围。
3. 展示行情价格、24 小时开盘/高低、实际数据源、更新时间、缓存状态与失败原因。
4. 基于 EMA20/50/200、MACD、RSI(14)、布林位置和 ATR(14) 计算确定性规则分数，并显示止损/止盈参考。
5. 支持图表缩放、横向移动、悬停、区间框选与区间高低点标注。
6. 提供多周期共振、研究型回测、方向概率、BTC 与 SPY/QQQ 联动、形态与关键位、仓位盈亏及强平风险研究功能。
7. 页面在数据请求失败时保留最近一次成功数据，并向用户说明失败原因。
8. 默认中文界面，并支持页面内中英文切换（如前端已加载对应组件）。

## 非功能需求

- Node.js 18+，本地监听 `127.0.0.1:8787`，不暴露到局域网。
- 首屏只请求当前行情与当前图表；额外研究数据由用户交互后请求。
- 上游请求超时为 4 秒；短时缓存用于抑制重复请求。
- 不存储账户、交易所密钥或用户身份数据；仓位表单仅保存在浏览器本地存储。

## 边界与风险

- 信号、预测、回测、强平价和概率均为研究性估算，不是交易指令或收益承诺。
- 回测未完整计入手续费、滑点、资金费率等真实交易成本。
- 行情依赖公开接口与用户网络，数据延迟、接口变更或不可用均可能影响展示。
