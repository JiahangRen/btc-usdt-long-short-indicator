## 1. 当前任务目标

BTC Indicator 是 BTC/USDT 的本地市场观察与研究面板。产品目标是：

1. 提供可追溯的实时行情、K 线、指标、规则信号和风险参考。
2. 在公开交易所接口暂时失败时，优先保留最近一次有效数据，减少空白页面和超时。
3. 支持每位访问者在自己的浏览器内创建价格与爆仓价提醒。
4. 明确区分研究信息、测试推送和真实规则触发；不提供自动交易，也不构成投资建议。

## 2. 产品与技术说明

系统结构：

    浏览器：public/index.html、public/app.js、public/styles.css
       │ HTTP / JSON
    Node 服务：server.mjs，默认监听 127.0.0.1:8787
       │ HTTPS / WebSocket
    OKX、Coinbase、Gate、Binance 等公开数据源

浏览器会把 SendKey 和提醒规则保存在当前站点的 localStorage。只有用户填写 SendKey 后，浏览器才会直接调用 Server酱 API；项目服务器和 SQLite 不接收、不保存该凭证。

本地数据保存于 data/market.sqlite，内容包括报价、K 线、市场结构、新闻、情绪、宏观日历和研究结果。该数据库不是完整逐笔行情库。

常用命令：

    npm start
    npm run check
    curl http://127.0.0.1:8787/api/status

## 3. 已完成的修改

### 行情稳定性

- 主图默认数量为 360 根 K 线，降低服务端请求和前端绘制负担。
- 增强了上游超时、短期缓存、最近成功快照和回退逻辑。
- 扩展 SQLite 的研究候选训练、影子 A/B、盘口 OFI 等记录能力。
- 对部分宏观日历增加可见的保守回退，避免官方源短暂不可读时模块整体空白。

### 本地消息推送

- 新增消息推送板块和多规则列表。
- 支持：价格达到、价格上涨至、价格下跌至、多头爆仓价、空头爆仓价。
- 新增交易所风格的添加预警弹层。
- 重复提醒可配置每条规则的冷却时间；仅提醒一次不显示也不使用冷却时间。
- 新增测试当前市价和测试当前规则（不保存）两种测试。
- 测试当前规则会使用编辑中的规则类型和目标价发送消息，不会创建规则、不会改变已有冷却状态。
- 测试成功提示已从浏览器原生提示框改为站内深色遮罩弹层。

### 当前通知文案规范

测试价格规则：

    价格告警【测试】 BTC价格上涨至 77,556

测试爆仓规则：

    爆仓告警【测试】 BTC价格接近多头爆仓价 77,531

正式价格规则：

    【价格】BTC价格上涨至 77,556
    【价格】BTC价格下跌至 77,556

正式爆仓规则：

    【爆仓】接近多头爆仓价 77,531
    【爆仓】接近空头爆仓价 77,531

上述价格为格式示例。实际规则通知将使用用户设置的目标价格，详情正文同时可显示触发瞬间市价。

当前微信服务号会在前面展示设备收信，这不是项目写入的消息标题或正文，无法通过网页 API 删除。若要完全改变来源标识或消息卡片展示，需要用户在 Server酱控制台切换消息通道，例如企业微信应用消息或 Server酱³ App。

### 脚本缓存

public/index.html 为 app.js 添加了版本查询参数。目前版本为 20260902-v231。以后更新 app.js 后必须递增该版本，避免浏览器继续使用旧脚本。
