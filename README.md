# BTC Indicator (rebuilt)

一个本地运行的 BTC/USDT 图表与规则信号工具。它不承诺交易收益，也不把规则打分伪装成机器学习。

## 启动

需要 Node.js 18+：

```bash
npm start
```

打开 <http://127.0.0.1:8787>。浏览器只连接本地服务，因此不会因 `file://` 或交易所 CORS 而空白。

## 设计原则

- 首屏仅请求：当前价格与当前图表。区间收益和多周期共振均为用户点击后才请求。
- 服务端并行探测 Gate、OKX、Binance；第一个有效响应即使用，并在 15 秒内复用缓存。
- 页面明确显示数据源、数据时间、缓存状态和错误原因；最近一次成功数据会保留，不会被 `--` 覆盖。
- 时间范围只有可验证的 `1D / 1W / 1M / 6M / 1Y`，不会展示“全部历史”或无法保证的 10 年数据。
- “规则信号”是 EMA、MACD、RSI、布林带与 ATR 的确定性计算；回测只作研究演示，未计手续费、滑点和资金费率。

## 本地数据存储

服务使用内置 SQLite 保存到 `data/market.sqlite`（该目录不提交到 Git）：

- `quote_snapshots`：最新报价快照，最小写入间隔 5 秒，保留 7 天；
- `candles`：按数据源、K 线周期与时间去重的 OHLCV，保留 90 天；
- `market_snapshots`：图表请求摘要，保留 30 天；
- `training_runs`：历史训练样本刷新记录，保留 180 天。

可访问 `/api/status` 查看当前 SQLite 记录数。Docker Compose 已将 `./data` 挂载到容器，重建容器不会删除数据库。

如果本机也无法访问交易所域名，请在运行服务的终端配置可用网络/代理后再刷新。服务端会在页面上返回每个源的失败原因。
